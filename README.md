# AI_Resume_Screening_Project
Companies receive a large number of resumes for every job opening. Manually reviewing and comparing these resumes is time-consuming, repetitive, and prone to human error. Recruiters may also miss qualified candidates when screening hundreds of applications.
The objective of this project is to develop an AI-powered Resume Screening System that automatically analyzes resumes and compares them with a given job description.
The system:
Accept a Job Description and multiple resumes.
Extract relevant information such as skills, education, and work experience.
Identify the skills and requirements mentioned in the job description.
Compare each candidate's qualifications with the job requirements using Machine Learning/NLP techniques.
Calculate a matching score for each candidate.
Rank candidates based on their relevance to the job.
Help recruiters quickly identify the most suitable candidates for further evaluation.
The system should act as a decision-support tool for recruiters, reducing manual effort and making the initial resume screening process faster and more consistent.
